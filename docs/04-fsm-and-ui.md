# 1. Принципы интерфейса

- Пользователь не должен запоминать внутренние ID.
- Все основные действия доступны через клавиатуру.
- В FSM всегда должна быть возможность отменить действие.
- Во вложенных меню должна быть кнопка `← Назад`.
- VK-бот не использует модель Telegram slash-команд.
- Telegram-бот может использовать `/start` и служебную команду регистрации чата.
- Пагинация VK-клавиатуры не используется.
- Список топиков выводится текстом с порядковыми номерами.

---

# 2. VK-бот — главное меню

Постоянная клавиатура:

- `Алиасы`
- `Помощь`

Ручная пересылка запускается не кнопкой, а фактом получения одного пересланного сообщения.

---

# 3. VK-бот — Help

Одинаковую справку открывают (регистронезависемый):

- `Начать`;
- `Помощь`;
- `Помоги`;
- `Help`;
- кнопка `Помощь`.

Справка содержит:

1. как вручную переслать одно сообщение;
2. как выбрать топик по номеру;
3. как использовать алиас;
4. как создать / изменить алиас;
5. как отменить операцию;
6. что автоматически пересылаются сообщения с `@all` и/или хештегом, если соответствующие функции включены.

# 4. VK-бот — ручная пересылка

## State: IDLE

Обычное состояние.

### Event: получено одно пересланное сообщение

Переход → `WAIT_DESTINATION`.

Бот сохраняет только это сообщение как pending message.

Бот отвечает:

```text
Куда отправить сообщение?

1. Важные
2. Группа 01-24
3. Группа 02-24

Можно отправить только номер топика.
```

Клавиатура:

- `Отмена`

### Event: получено два или более сообщений

FSM не запускается.

Ответ:

```text
Можно переслать только одно сообщение за одну операцию.
Отправьте одно сообщение отдельно.
```

---

## State: WAIT_DESTINATION

Допустимый ввод:

- номер топика;
- `Отмена`.

### Если введён корректный номер

Переход → `SENDING`.

### Если номер не существует

Бот отвечает:

```text
Номер не найден.

Выберите топик по номеру:

1. Важные
2. Группа 01-24
3. Группа 02-24
```

FSM остаётся в `WAIT_DESTINATION`.

### Если `Отмена`

Pending message удаляется.

Переход → `IDLE`.

---

## State: SENDING

Бот пытается создать Telegram-публикацию.

### Success

Бот сообщает об успешной отправке.

Pending message очищается.

Переход → `IDLE`.

### Failure

Бот сообщает понятную ошибку.

Pending message очищается либо возвращается в `WAIT_DESTINATION` — конкретное поведение определяется типом ошибки.

# 5. VK-бот — FSM алиасов

## Вход

Пользователь нажимает `Алиасы`.

Бот показывает:

```text
Telegram-топики:

1. Важные — алиас: важное
2. Группа 01-24 — алиас: 1
3. Группа 02-24 — алиас: 2
4. Новости — алиас не задан
```

Клавиатура:

- `Добавить`
- `Изменить`
- `Удалить`
- `← Назад`

---

## 5.1. Добавить алиас

### State: ALIAS_ADD_WAIT_TOPIC

Бот:

```text
Введите номер топика, для которого хотите добавить алиас.
```

Клавиатура:

- `Отмена`

После корректного номера → `ALIAS_ADD_WAIT_VALUE`.

### State: ALIAS_ADD_WAIT_VALUE

Бот:

```text
Введите новый алиас.
```

Проверки:

- алиас не пустой;
- без пробелов;
- не занят другим алиасом пользователя;
- не совпадает с системными командами / кнопками;
- регистр при сравнении игнорируется.

При успехе:

```text
Алиас "важное" назначен топику "Важные".
```

Переход в главное меню алиасов.

---

## 5.2. Изменить алиас

### State: ALIAS_EDIT_WAIT_TOPIC

Бот просит номер топика.

После корректного номера показывает текущий алиас и переходит → `ALIAS_EDIT_WAIT_VALUE`.

### State: ALIAS_EDIT_WAIT_VALUE

Бот просит новый алиас.

После успешной валидации старое значение заменяется.

Возврат в меню алиасов.

---

## 5.3. Удалить алиас

### State: ALIAS_DELETE_WAIT_TOPIC

Бот просит номер топика.

Если алиас существует:

```text
Удалить алиас "важное" у топика "Важные"?
```

Кнопки:

- `Да`
- `Отмена`

После `Да` алиас удаляется.

# 6. Telegram-бот — доступ

На любое входящее событие сначала проверяется Telegram User ID.

## Authorized

ID есть в `OWNER_IDS`.

Обработка продолжается.

## Unauthorized

ID нет в `OWNER_IDS`.

Бот:

- не отвечает;
- не показывает клавиатуру;
- не сообщает причину отказа.

---

# 7. Telegram-бот — первичная настройка

## State: TG_UNREGISTERED

Owner отправляет `/start`.

Бот отвечает:

```text
Telegram-чат ещё не зарегистрирован.

1. Добавьте этого бота в нужный Telegram-чат.
2. Выдайте ему необходимые права.
3. Выполните команду регистрации внутри этого чата.
```

Конкретное имя команды регистрации определяется при реализации.

---

## Регистрация внутри Telegram-чата

После получения команды регистрации:

1. проверить, что инициатор — owner;
2. определить chat id;
3. проверить необходимые права бота;
4. при недостатке прав остановить мастер;
5. явно перечислить недостающие права;
6. потребовать выдать права и повторить проверку;
7. после успеха сохранить Telegram-чат;
8. через Telethon получить список топиков;
9. сохранить актуальные топики;
10. завершить первоначальный мастер.

Owner получает актуальную главную клавиатуру.

---

# 8. Telegram-бот — главное меню owner

После регистрации чата клавиатура содержит:

- `Включить/Отключить автопересылку по @all`
- `Включить/Отключить автопересылку по хештегам`
- `Включить/Отключить автопересылку постов сообщества`
- `Настроить топик назначения автопересылки постов стены`
- `Настроить топик назначения автопересылки сообщений чата`
- `Список настроек топиков`
- `Сменить Telegram-чат`

Текст каждой toggle-кнопки зависит от текущего состояния.

---

# 9. Toggle-кнопки

Есть три независимых toggle:

1. `@all`;
2. хештеги;
3. посты стены.

## Если функция включена

Кнопка:

```text
Отключить автопересылку ...
```

## Если функция выключена

Кнопка:

```text
Включить автопересылку ...
```

После нажатия:

1. значение меняется;
2. сохраняется в SQLite;
3. owner получает подтверждение;
4. всем owners отправляется уведомление об изменении, кроме овнера который выполнил изменение. Ему просто прилетает обновленная клавиатура;
5. всем owners отправляется актуальная обновлённая клавиатура.

`/start` всегда формирует клавиатуру заново из текущего состояния БД.

---

# 10. Настройка топика сообщений VK-чата

Owner нажимает:

`Настроить топик назначения автопересылки сообщений чата`

Бот выводит актуальный список:

```text
Выберите топик:

1. Важные
2. Общий чат
3. Группа 01-24
4. Группа 02-24
```

Клавиатура:

- `Отмена`
- `← Назад`

FSM ожидает порядковый номер.

## Корректный номер

Бот сохраняет topic id.

Ответ:

```text
Топик для автоматической пересылки сообщений VK:
Важные
```

## Некорректный номер

Бот сообщает об ошибке и повторяет список.

---

# 11. Настройка топика стены VK

Owner нажимает:

`Настроить топик назначения автопересылки постов стены`

Механика аналогична настройке топика сообщений VK-чата.

Выбранный topic id сохраняется отдельно.

---

# 12. Список настроек топиков

Owner нажимает:

`Список настроек топиков`

Бот выводит только полезное состояние привязок, например:

```text
Настройки топиков:

Важные
└ Сообщения VK-чата

Новости сообщества
└ Посты стены VK
```

Если назначение не задано:

```text
Сообщения VK-чата:
не настроено

Посты стены VK:
не настроено
```

Клавиатура:

- `Обновить список`
- `← Назад`

---

# 13. Обновление списка топиков

Owner нажимает `Обновить список`.

Бот:

1. обращается к Telethon;
2. получает актуальный список топиков зарегистрированного Telegram-чата;
3. обновляет локальные данные;
4. проверяет, существуют ли назначенные топики;
5. показывает обновлённый список.

Если назначенный топик исчез:

- настройка может оставаться сохранённой для диагностики;
- owner получает явное предупреждение;
- при реальной публикации используется General fallback.

---

# 14. Смена Telegram-чата

Owner нажимает:

`Сменить Telegram-чат`

Бот:

```text
Текущий Telegram-чат будет отвязан.
Все настройки Telegram-интеграции будут сброшены до заводского состояния.

Продолжить?
```

Кнопки:

- `Да`
- `Отмена`

## `Отмена`

Ничего не меняется.

## `Да`

Удаляются:

- зарегистрированный Telegram-чат;
- выбранный топик сообщений VK-чата;
- выбранный топик стены;
- сохранённые привязки топиков.

Toggle возвращаются к default:

- `@all` — включено;
- хештеги — включены;
- посты стены — включены.

FSM возвращается в `TG_UNREGISTERED`.

---

# 15. Навигация и отмена

Правило для всех FSM:

- `← Назад` возвращает на предыдущий экран;
- `Отмена` завершает текущую изменяющую операцию;
- отменённая операция не должна частично менять БД.

VK-бот не использует пагинацию клавиатуры.

Telegram-бот также не обязан использовать пагинацию, пока список топиков остаётся разумного размера; сами топики выводятся текстовым списком с номерами.

---

# 16. Уведомления owners

## Обязательно всем owners

Уведомлять всех owners:

- после изменения любого toggle;
- если настроенный топик недоступен и использован General fallback;
- при критической ошибке рабочей конфигурации, которую возможно сообщить уже запущенным приложением.

## Не требуется массовое уведомление

Не рассылать всем owners отдельные уведомления:

- об ошибке конкретного видео;
- о файле > 50 МБ;
- о неподдерживаемом attachment.

Такие ошибки отображаются внутри соответствующей Telegram-публикации.
