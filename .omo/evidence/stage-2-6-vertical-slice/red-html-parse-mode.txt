# RED: realBot API rejected /topics because a global parse_mode=HTML parsed the literal "<номер>"

## Production traceback (user run, 2026-09-18 09:26):
aiogram.exceptions.TelegramBadRequest: Telegram server says - Bad Request:
can't parse entities: Unsupported start tag "номер" at byte offset 246
  File ".../presentation/telegram/routers/destination.py", line 89, in handle_topics
    await message.answer(...)

## Root cause (empirically verified against aiogram 3.31):
- create_bot() applied DefaultBotProperties(parse_mode=ParseMode.HTML) globally.
- Every Message.answer() therefore sent parse_mode=HTML, including owner replies.
- Literal '<номер>' and any '<' in chat/topic titles became an unintended HTML tag.
